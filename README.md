## Описание проекта
Проект предназначен для изучения работы интерфейса APB (Advanced Peripheral Bus). Реализованы мастер и подчинённое устройство (Slave), обеспечивающие обмен данными посредством операций записи и чтения.

## Функциональность
- Передача данных по интерфейсу APB.
- Запись данных в регистры Slave.
- Чтение данных из регистров.
- Обработка ошибок обращения.
- Проверка работы с помощью Testbench.\
